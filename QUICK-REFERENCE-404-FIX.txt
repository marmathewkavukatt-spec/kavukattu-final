================================================================================
TROUBLESHOOTING
================================================================================

Still seeing errors?

1. Verify .next exists on server
   - Check via File Manager
   - Confirm .next/static/chunks/ has files

2. Check Node.js settings
   - Version: 18.x or higher
   - Mode: Production
   - Startup: node_modules/next/dist/bin/next start

3. Clear browser cache
   - Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
   - Or test in Incognito mode

4. Check server logs
   - Hostinger Dashboard → Logs
   - Look for errors

5. Nuclear option
   ssh to server:
   rm -rf .next node_modules
   npm install
   npm run build
   pm2 restart all
